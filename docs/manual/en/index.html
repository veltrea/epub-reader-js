EPUB reader for macOS and Windows

Not strict correctness,
but books that simply read well.

Japanese vertical EPUBs have long been made with few reference implementations to check against. This reader quietly absorbs rough markup and brings the book to a readable form, yet shows exactly what the book specifies when you want to know. Read-aloud, audio export, narrated video and translation are all included.

1

Two render modes

Some days you want the book’s rough edges smoothed over so you can read; other days you want to see those rough edges. One app switches between both.

Default

Reading-friendly (friendly)

Absorbs rough markup on the EPUB side and brings the book close to how it is expected to look.

  • Fits images inside the frame
  • Restores the proportions of SVG covers squashed by preserveAspectRatio="none"
  • Fixes misaligned hanging indents
  • Rescues table-of-contents entries whose links are broken
The other

As authored (raw)

Turns the corrections above off and shows what the engine draws from exactly what the EPUB specifies. Distorted covers and markup that has no effect appear as they are.

  • Check the book without corrections
  • Colours, text size, line spacing and custom CSS still apply in raw (they are reading settings, not an interpretation of the EPUB)

In both modes, a book that says it is vertical but ends up laid out horizontally is set vertically, and image-only pages such as covers and frontispieces are enlarged to fill the screen.

As a preview you can hand to writers. For writers who are not familiar with EPUB technology, even the position of a single page break can be a worry. A tool that lets you say “this is a preview; the final look varies by platform” makes the conversation much easier.
2

Read aloud

The best way to check a manuscript turned out to be pairing it with text-to-speech. That is why read-aloud has had a lot of work.

High-quality voices, from any position

  • Synthesized speech with VOICEVOX / AivisSpeech. If the engine is not running, the app tries to start it
  • Adjust the voice, the speed and the length of pauses at line breaks and punctuation
  • Start reading from wherever you double-click in the text
  • Space plays and pauses; Enter / Esc stops
  • Pages turn along with the speech; the sentence being read is highlighted, and the part already spoken fills in karaoke style

A reading dictionary with layer priorities

In Japanese TTS, the fact that short words are matched first causes trouble. Register a character named 明 to be read Akira, and 明日 (tomorrow), 明確 (clear), 明暗 (light and dark) and 説明 (explanation) all turn into Akira as well.

The speech engines’ user dictionaries have no way to prevent this, so the app has its own reading dictionary in which each word has a priority (layers 1 to 10). Replacements go from the highest layer down, and parts already replaced are left alone by lower layers. Put the name on a low layer and the compound words that appear in that book on a high layer, and the compound words are settled first, so only a standalone 明 is read differently. Regular expressions (patterns such as 第(\d+)話) are supported too.

The dictionary is split into “All books” and “This book only”. A reading used only in one work, such as a character’s name, can be registered without carrying it into other books. Adding an entry and browsing saved entries happen in separate screens, so you never have to go through a long list just to add one word. If you try to register a word you registered before, the screen opens with its saved reading.

An AI can take over the tedious registering. The dictionary can be operated from outside, not only from the screen: AI agents can use the bundled test bus (a way to send commands) through MCP. Collect the words containing that character from the text, load them in, and check the text that will be sent to read-aloud with applyRules — because this round trip can run on its own, building a dictionary for a whole book is less work than you might expect. The test bus is turned off in the released app, so launch the app with an environment variable to use it. The steps are in chapter 8 of the manual.

Export

Not just for reading: take it with you. No screen recorder or video editor is needed.

Audio per chapter (WAV)

Listen to your own novel on the train, or check a work your group is making in spare moments. The chapter you are reading is turned into a single audio file.

Narrated video (MP4)

Exports a narrated video combining the look of the text with the spoken audio. Vertical or horizontal layout is chosen automatically. Publishing your own work as a video becomes much easier.

Both audio and video are exported entirely within the app. You do not need to install anything else.

4

Tools for keeping on reading

Reading without lifting a hand, falling asleep while listening: small tools fitted to how you read.

Auto page turn

Turns to the next page every 10 to 90 seconds, or any number from 1 to 3600 seconds. It does not turn while reading aloud, and stops by itself at the end of the book.

Sleep timer

Stops read-aloud after 15 to 120 minutes. When it expires it can also put the computer to sleep or shut it down (shutdown waits 30 seconds, so you can cancel it with “Cancel Timer” if you are still awake).

Bookmarks and search

Select a sentence in the text and right-click, and that sentence becomes a bookmark listed as it is. Search the text with ⌘F.

Translation

Connects to an OpenAI-compatible API (LM Studio or Ollama on your machine, or a cloud service) and shows a translation of the paragraphs on screen beside the original. The layout of the text stays as it is.

5

Library

So you can find books as your collection grows — and so books you do not want seen are reliably never shown.

Arrange, group, find

  • Drag and drop books or folders onto the window (subfolders are searched and everything is added at once). Besides EPUB, it opens CBZ, FB2, MOBI, AZW3 and more
  • A sidebar with collections (can be nested), favourites and unfiled books
  • Filter and sort by title, author or publisher
  • By author view with a Japanese kana index (you can correct the reading of an author’s name by hand)
  • A “Continue Reading” row so you can pick up from the last book you read

Switch the whole shelf

A collection can include books you would not show others: data you hold for work, books you would rather your family did not see, books that have nothing to do with the person you are sharing your screen with. So you can have several shelves.

It is not a “hide” feature because with hiding, missing a single path — forgetting to turn it back on, covers left in the cache — is enough to leak. With a design that switches what is read, anything not read cannot be shown. Deleting a shelf keeps its data in Deleted/.

For developers

From here on, this is about how the app itself is built. It includes a way to find mismatches between the manual and the code by machine, and a way to test a GUI app automatically without clicking on screen coordinates.

Finding mismatches between the manual and the code by machine

Documentation may be right when written, but when only the code moves on, it silently becomes wrong. People cannot prevent that by reading, so it is checked by machine.

  • Extracting the list of features from the code — menu ids, settings keys, test bus commands and supported file extensions are already declared in the code. They are extracted with grep instead of guessed, and compared against the records. Whatever has been added is exactly what needs documenting
  • Finding missing explanations in reverse — ids are attached to features in the code, and the same ids are embedded in the manual as invisible markers. Comparing the two sets reveals both features with no explanation and explanations with no feature behind them
  • Forbidding UI text written directly in the code — writing Japanese directly into the code makes the check fail. So does a mismatch in the number of keys between the Japanese and English language files

E2E tests that do not rely on computer use

  • No coordinate clicks — the screen is driven by sending commands to a command bus inside the app
  • In-app command bus — everything down to bulk-loading and checking the reading dictionary can be driven by commands from outside. However, it is closed in the released app. Commands run with the app’s permissions, so leaving the port open would let any local process that grabbed the port first take screenshots or write files. It works only in debug builds, or when the app is launched with EPUB_READER_TESTBUS=1
  • Assertions in numbers — not “it looks off” but “it overflows the frame to the right by 12.3pt”
  • Each test finishes in a few seconds

How to use it is in the “Test bus” section of DEVELOPMENT.md.

Download

The built app is on GitHub Releases: a macOS version (DMG and ZIP, for Apple Silicon) and a Windows version (ZIP).

macOS

Open the DMG and drag epub-reader.app to Applications. The app has an ad-hoc signature, without an Apple Developer account ($99 a year), so the first launch needs one step past the macOS warning. Once allowed, it keeps launching normally.

  1. System Settings → Privacy & Security → “Open Anyway” (on macOS 15 and later, right-click → “Open” no longer works)
  2. If you prefer a command:
xattr -dr com.apple.quarantine /Applications/epub-reader.app

To use it on an Intel Mac, build it yourself from source.

Windows 11

The ZIP contains a single epub-reader.exe. Put it anywhere and run it. The first time, “Windows protected your PC” may appear. Press “More info”, then “Run anyway”.

The app is neither notarized by Apple nor code-signed for Windows. If you need that, fork the project and sign it with your own certificate.

State of this software

It was made for personal use, and some parts are not thoroughly tested. It is published on the view that not everything has to be finished to product quality before it can be released. The basic features alone should be quite usable.

The Windows version has been checked less thoroughly than the macOS version. Importing by drag and drop, the file picker, sleep and shut down, and starting the speech engine automatically have not yet been tried on a real Windows machine. There is no Linux version.
