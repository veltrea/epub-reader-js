Manual

From installation to export, in the order you would try things while reading along. Every screenshot is of the actual app, taken on macOS with the Japanese interface. Windows shows the same items, with the menu bar inside the window instead of at the top of the screen. The English interface has the same items in the same places, with the English names used in this manual.

1Requirements and installation

Requirements
macOS and Windows 11 (64-bit). There is no Linux version. The macOS release is built for Apple Silicon. On an Intel Mac, build it yourself from source. Windows needs WebView2, which comes with Windows 11.
Files it opens
EPUB (reflowable and fixed-layout), CBZ, FB2 / FBZ, MOBI / AZW / AZW3 / KF8. Any other format is refused. Reflowable EPUB is where the effort has gone.
Needed for read-aloud
VOICEVOX or AivisSpeech. Neither is bundled, so install one yourself. Not needed if you do not use read-aloud.
Needed for translation
An OpenAI-compatible API: a server on your own machine (LM Studio, Ollama) or a cloud service. Not needed if you do not use translation.

Installing on macOS

  1. From Releases, download the file whose name ends in -macos.dmg or -macos.zip.
  2. For the DMG, open it and drag epub-reader.app to Applications. For the ZIP, unpack it and move the app into /Applications.
  3. The first time, macOS refuses to open it because the developer cannot be verified. Go to System Settings → Privacy & Security → “Open Anyway”.

On macOS 15 and later, right-click → “Open” no longer gets past this check. If you prefer a command, removing the attribute also works: 

xattr -dr com.apple.quarantine /Applications/epub-reader.app
Why this step is needed. The app is distributed with an ad-hoc signature, without an Apple Developer account ($99 a year), and it is not notarized by Apple. The signature of the released app does not change, so once you allow it, it keeps launching normally. A copy you build yourself from source does not trigger the check.

Installing on Windows

  1. From Releases, download the file whose name ends in -windows.zip.
  2. It contains a single epub-reader.exe. It is not an installer: put it in any folder and run it.
  3. The first time, a blue “Windows protected your PC” screen may appear. Press “More info”, and a “Run anyway” button appears; use that.
The Windows version has been checked less thoroughly than the macOS version. Importing by drag and drop, the file and folder pickers, sleep and shut down, and starting the speech engine automatically have not yet been tried on a real Windows machine. Some of the menu layout still follows macOS conventions.

2The first five minutes

Leave the detailed settings for later and get to the point where you can read.

  1. Launch the app. The first screen is the library, with a sample book for checking that things work.
  2. Drag and drop a book of your own (or a folder of books) onto the window. If you drop a single book, it opens once it has been imported.
  3. Click a cover in the library to open it. A vertical book appears ready to read from right to left.
  4. Turn pages by clicking the left or right edge of the screen, with the arrow keys, or with the mouse wheel. Adjust the text size with + and -.
  5. To use read-aloud, double-click where you want it to start. If VOICEVOX or AivisSpeech is not running, the app tries to start it.

From here on, read only the parts you need. If your library is growing, go to chapter 4; to change how books look, chapter 6; to fall asleep listening, chapter 11.

3Adding books

Every method goes through the same process. Use whichever suits you.

  • Drag and drop — drop books or folders onto the window. This works while you are reading, too. If you drop a single book, it opens once imported; if you drop several, you stay in the library
  • The “Add books” button — top right of the library. It offers “Choose Files…” and “Add from Folder”
  • File > Open… (⌘O) — a window for choosing books. You can select several
  • File > Add from Folder… (⇧⌘O) — adds all the books in a folder
  • From Finder or File Explorer — double-click a book file to open it in this app

When you give it a folder, it searches subfolders too and adds only files in supported formats. Hidden files are skipped, and it looks at up to 5,000 files at a time. Files in unsupported formats are ignored on purpose: dropping one on the window does nothing.

While several books are being added, progress is shown. Press “Stop” to stop; the books added so far stay. For a large fixed-layout book, extracting the cover can take tens of seconds.

Imported books are copied into the app’s data folder. Moving or deleting the original file afterwards does not affect the book in the library. Conversely, deleting a book from the library removes only the copy; your original file stays. Importing the same file from the same place again does not add it twice. The location of the data folder is in chapter 16.

4Using the library

Finding and sorting

  • Filter — the box at the top. Choose what it searches: All, Title, Author or Publisher
  • Sort — Recently opened, Title, Author or Publisher. Shown only in the grid view
  • View — “Grid” or “By author”. Switch with the two buttons at the top right

Collections

Create one with the + next to “Collections” in the sidebar, with “New Collection…” at the bottom of the sidebar, or by right-clicking a book → “Add to a New Collection…”. You can also drag a book onto a collection in the sidebar. A book can be in several collections.

Collections can be nested. Right-click a collection for “Rename Collection”, “New Subcollection”, “Move to Top Level”, “Move Under” and “Delete Collection”. Deleting a collection does not delete its books, and its subcollections move up one level. Selecting a collection also shows the books in its subcollections.

What you can do by right-clicking a book

  • Add to Favourites / Remove from Favourites
  • Add to or remove from a collection (you can create a new collection on the spot)
  • Edit reading — used for the kana order of the By author view
  • Delete — removes the book from the library after confirming. The book’s bookmarks, reading position, its own reading dictionary, custom CSS and display settings go with it. Your original file is not deleted

5Reading a book

Bringing up the toolbars (read this first)

When you open a book, only the text is shown and the buttons are hidden, so the text can use as much of the screen as possible. The toolbars show for about two seconds right after the book opens.

  • Move the mouse to the top edge of the screen to bring up the top toolbar
  • Move the mouse to the bottom edge of the screen to bring up the bottom toolbar
  • Move the mouse back over the text, and they hide again
  • Everything is also reachable from the menus without the toolbars. ⌘L goes back to the library

The bottom toolbar has a slider for your position in the whole book, and buttons for “Read aloud”, “Stop”, “Save this chapter as audio”, “Save this chapter as a read-along video (MP4)”, “Auto Page Turn” and “Sleep Timer”. Drag the slider to jump anywhere in the book. In a right-to-left book, the slider also runs right to left.

Your reading position is saved automatically every time the page changes, and the book reopens there next time.

Contents

The branches down to the chapter you are reading open automatically. Branches you opened yourself stay open when the chapter changes.

Bookmarks

To bookmark the current page, use the bookmark button in the toolbar or “Go > Add Bookmark” (⌘D). Select a sentence in the text and right-click to bookmark that sentence.

What a change applies to depends on the item and where you are. Text size, line spacing, theme and margins always change the setting shared by all books. Rendering mode, writing direction, binding direction and spreads changed from the menu or toolbar while a book is open are remembered for that book only. If you pick the same value as the default again, the book stops holding its own setting, so it follows the default if you change the default later. Changing them from the menu while in the library, or in Settings, changes the default for all books. A book that has its own setting keeps using that.

When to use each rendering mode

Reading-friendly (default)
Absorbs rough markup in the EPUB and brings the book to a form that simply reads well. In particular, it:
  • Fits images inside the frame
  • Restores the proportions of SVG covers squashed by preserveAspectRatio="none"
  • Fixes misaligned hanging indents
  • Rescues table-of-contents entries whose links are broken by finding where they should go
  • Hides footnotes and endnotes placed in aside elements from the flow of the text
As authored
Turns the corrections above off, so you see what the engine draws from exactly what the EPUB specifies. Colours, text size, line spacing and custom CSS still apply in “As authored”, because they are reading settings, not an interpretation of the EPUB.

The following work in both modes: enlarging image-only pages (covers, frontispieces) to fill the screen, the image page spread and aspect-ratio settings, inferring vertical writing (next section), and leaving ruby out of read-aloud.

If a book does not appear vertically

EPUBs often lack the vertical-writing declaration. So the app compares whether the book says it is vertical with how it was actually laid out. If a book whose OPF primary-writing-mode is vertical, or a right-to-left book in Japanese, ends up laid out horizontally, the app sets it vertically. Books with EBPAJ-style class names (such as vrtl) get the matching direction filled in.

If it is still wrong, open the book and choose “View > Writing Direction > Vertical”. It is remembered for that book. The text-direction button in the toolbar also cycles through “auto → vertical (forced) → horizontal (forced)” each time you press it. Your reading position stays where it was.

MOBI and AZW books come out horizontal even when the book is vertical, because the old MOBI format has nowhere to record vertical writing. This setting puts them back. AZW3 and KF8 stay vertical on their own.

If a spread pairs the wrong pages

For a fixed-layout book (photo books, manga), a “Shift spread” button appears in the toolbar. If the pictures come out split across the wrong pages, for example because of the number of cover pages, press it to shift the pairing by one page so the right pages face each other. This is saved per book.

7Read aloud

Preparing

  1. Install VOICEVOX (or AivisSpeech).
  2. Open “Settings…” (⌘,) and choose the engine in the “Speech” tab.
  3. When “Engine status” shows Connected, you are ready.
  4. Choose the voice, speed and pause length, then press “Save”. “Test voice” plays a sample with the values on screen, before you save.

You do not have to start the engine yourself. If the engine does not respond when read-aloud starts, the app starts it and waits up to 40 seconds for it to be ready. Meanwhile the bottom of the screen says “Starting the speech engine…”. Only VOICEVOX and AivisSpeech can be started this way. With “Custom URL”, start the engine yourself.

Starting read-aloud

Double-click the textStarts reading from that word
Space / ⌘RPlay / pause (resumes from where it paused)
Enter / Esc / ⌘.Stop
Bottom toolbar“Read aloud” and “Stop” buttons
“Read Aloud” menuPlay / Pause, Stop, Add to Reading Dictionary…, Edit Reading Dictionary…, Sleep Timer

While reading, the sentence being read is highlighted in yellow, and the part already spoken fills in with a stronger colour in time with the voice (karaoke style). At the end of a page or chapter it moves on by itself and keeps reading to the end of the book. The next sentences are synthesized in the background ahead of time, so there is hardly any wait between sentences. Ruby is shown on screen but is not read a second time.

If synthesis fails twice in a row, the app assumes the engine cannot be reached and stops reading.

8Reading dictionary

Use this to register words that the speech engine would otherwise read wrongly, such as character names and coined words. It affects only read-aloud; the text on screen does not change. The speech engines’ own user dictionaries are not used: the app replaces the text itself before passing it to the engine.

This dictionary exists because of how Japanese works: the same kanji can be read in several ways, and the right reading depends on the word it belongs to. The examples below are Japanese, with the readings written in katakana.

Adding an entry and browsing saved entries happen in separate screens. That way, when you only want to add one word, you do not have to scroll through a long list of everything you have saved.

The two screens and how to open them
What you wantHow to open itScreen
Add one wordSelect the word in the text and right-click → “Add to Reading Dictionary”Add screen
Add one wordMenu “Read Aloud > Add to Reading Dictionary…”Add screen
Browse or fix saved entriesMenu “Read Aloud > Edit Reading Dictionary…”List screen

The add screen shows only the spelling, the reading and the options. Press “Done” to save and close. If you want to see the list, use “Browse saved entries” at the very bottom of the same screen. In the list, press a row to edit that entry, and press “‹” at the top left to go back to the list.

The trouble is one-character names

Suppose a character is named 明 (Akira). Read as it is, the engine says “Mei” or “Akari”, so you want to register 明 → アキラ. But the moment you do, every 明 in the text becomes Akira.

明日 (ashita, “tomorrow”) → Akira-bi　/　明確 (meikaku, “clear”) → Akira-kaku　/　明暗 (meian, “light and dark”) → Akira-an　/　説明 (setsumei, “explanation”) → setsu-Akira

Registering a short word drags in every longer word that contains it, and the speech engines’ user dictionaries have no way to prevent that.

The fix: the name low, the compound words high

Each entry in this dictionary has a layer (1 to 10), and replacements are made starting from the highest layer. Once a part of the text has been replaced, lower layers never touch it again. So the steps are:

  1. Put 明 → アキラ on a low layer (say, 2).
  2. Register the words containing 明 that appear in that book on a high layer (say, 8): 明日→アシタ, 明確→メイカク, 明暗→メイアン, 説明→セツメイ …

The compound words are settled first and locked, so only a 明 that belongs to no other word becomes Akira. A novel uses a limited set of such words, so once you have collected them, the book is read correctly from start to finish.

Use text search to collect the compound words. Search for the character with ⌘F, and every place it appears in the book is listed with the surrounding text. Working down that list as you register words means fewer are missed.

Within the same layer, longer spellings are settled first (entries tied to a spot come before even those). So even if you forget to set a layer, a short word is unlikely to take over a longer one.

A word you registered before opens with its saved reading

If you registered the selected word before, the app does not create a new, empty entry. It opens a screen filled in with the reading, layer and options you entered before. The heading also changes from “Add to the reading dictionary” to “Edit a saved reading”, so you can tell whether you are creating an entry or editing one.

This is because if the same spelling were registered twice, you could not tell which entry is in effect. It looks in the same order as read-aloud: “This book only” first, then “All books”. Pattern (regular expression) entries are not matched this way, because a pattern never equals the text you selected.

For all books, or for this book only

The dictionary is split in two. A reading used only in one work, such as a character’s name, can be registered without carrying it into other books.

 Where it appliesUse it for
All booksEvery book on that shelfGeneral fixes, such as reading 明日 as “ashita”
This book onlyOnly the book that is open nowThings read differently in other books, such as the names of that book’s characters

Choose which one with “Applies to” on the add screen. The two options sit side by side; press one. The default is “All books”, and you move an entry to the other side in the same place. When no book is open (in the library), there is no “this book”, so this choice is not shown.

When the same spelling is in both, the “This book only” entry is used. Delete it, and the reading from “All books” applies again.

Conditions on surrounding characters, without regular expressions

Registering a single kanji can change compound words too. Registering 行 as “okona” (as in “to carry out”) also changes 銀行 (ginkō, “bank”) and 旅行 (ryokō, “travel”). Besides putting the compound words on a higher layer, you can make the characters before and after it a condition.

Just choose from “Preceded by” and “Followed by” under “Surrounding characters” on the add screen. No regular expression is needed.

SpellingConditionResult
行Preceded by not a kanjiIn 「銀行と旅行、行った」, the compound words stay as they are; only the last 行 is read differently
行ったPreceded by hiragana「とり行った」 → 「とりオコナッタ」; 「銀行った」 does not change
年Preceded by a digitIn 「五年と5年」, only 「5年」 is read differently

The choices are: anything, hiragana, katakana, a kanji, not a kanji, and a digit. If you set both sides, the reading is replaced only when both conditions are met. Entries with different conditions are listed separately (“行 preceded by hiragana” and “行 preceded by a kanji” can be two entries).

Writing a pattern (regular expression)

Switch the control at the top of the add screen to “Pattern” to write a regular expression as the spelling. Parts in parentheses can be used in the reading as $1, $2 …; captured text is converted to katakana.

SpellingReadingResult
([0-9]+)年$1ネン「1927年」 → 「1927ネン」
(?<=[ぁ-ん])行ったオコナッタReplaced only when preceded by hiragana

A row that is not a valid regular expression is not used, and the screen says “Invalid regular expression. This row is ignored.”

Changing the reading in one spot only

Sometimes you want to change the reading of a word in just one place. Select the word in the text, right-click, and choose “Add a reading for this spot only”. The entry remembers the position (its layer starts at 9).

The position is a guide; the place actually changed is decided by matching the spelling. Different tools count characters differently, so trusting the position as it is could change a spot one character off. Instead, the app looks for the same spelling near the position you chose and changes that. If the same word appears twice nearby, only the one closest to your selection is changed.

You can change how far it looks with “How far to look (characters)” on the add screen (the default is 40). Press “Remove the spot” to turn it back into an ordinary entry that matches anywhere in the book. An entry tied to a spot cannot be tried in the “Test” box, because there is no position in the text to match against.

Other options

  • Insert boundaries around the reading — stops the word being parsed together with its neighbour and read wrongly. The silence a boundary creates is removed before synthesis, so nothing drags
  • Enabled — turns an entry off for a while without deleting it
  • Test — on the list screen. Type a sentence to see the result, replaced in the same order as read-aloud (All books → This book only)
The “All books” reading dictionary is kept per shelf (chapter 13), so you can keep proper nouns from work on a separate shelf. The “This book only” dictionary belongs to its book and is deleted along with the book.

Do you have to register everything by hand?

To be honest, this job is tedious. In a long novel, the words containing 明 alone can run to dozens, and typing them in one at a time is hard work.

So the app includes a way to operate the dictionary with commands from outside (the test bus). AI agents can use it through the bundled MCP server. The round trip — “find the words containing that character in the text → add them with readings → check the result against the exact text sent to read-aloud” — can run without a person typing each entry.

This is turned off in the released app. Commands run with the app’s permissions, so leaving it open would let other local processes take screenshots or write files. It works only in debug builds, or when the app is launched with the environment variable EPUB_READER_TESTBUS=1.

Here is how it works. The bundled relay in mcp/testbus-mcp/ listens on 127.0.0.1:47832 (loopback, so it cannot be reached from the network), and the app fetches commands from it. The app itself does not open a port. A small client that sends one command is tests/tb.mjs (both run on Node with no external dependencies). The commands are not limited to the dictionary; there are also commands for driving and capturing the screen.

Dictionary commands
CommandWhat it does
dictListReturns every entry
dictAddAdds one entry (spelling, reading, layer, boundaries, enabled, surrounding conditions, spot)
dictUpdate / dictDeleteEdits or deletes an entry
setRulesReplaces the whole dictionary (bulk load)
applyRulesApplies the dictionary to any text and returns the text that would be sent to read-aloud
openDictForm / openDictListOpens the add screen or the list screen (the same screens a person gets)

dictList, dictAdd, dictUpdate, dictDelete and setRules take scope: "common" (all books; the default) or "book" (this book only). dictList alone also accepts "merged" (the same order that is passed to read-aloud). To work with a “This book only” dictionary, open a book first. 

# Add a word
curl -s -XPOST http://127.0.0.1:47832/cmd -H 'Content-Type: application/json' \
  -d '{"cmd":"dictAdd","args":{"surface":"明暗","reading":"メイアン","layer":8}}'

# Check against the text sent to read-aloud
curl -s -XPOST http://127.0.0.1:47832/cmd -H 'Content-Type: application/json' \
  -d '{"cmd":"applyRules","args":{"text":"明は明日、明暗を明確に説明した。"}}'

The key is the last one, applyRules. You can tell whether the text will be read the way you intend from the text alone, without listening, so an agent can check its own entries and fix any that are wrong, again and again. Details are in the “Test bus” section of DEVELOPMENT.md.

9Translation

Translates the paragraphs currently on screen and shows the translation beside the original. The layout of the text is not touched, so vertical writing, spreads and ruby stay as they are.

Preparing

Translation connects to an OpenAI-compatible API. No translator is bundled.

On your own machine (nothing leaves it)
Install LM Studio or Ollama, load a model for translation, and start its server (LM Studio defaults to :1234, Ollama to :11434). In Settings → “Translation”, enter the Server URL, and once “Connection” shows it is connected, pick a model. Leave the API key blank.
With a cloud API
In the same tab, enter that service’s OpenAI-compatible address and your API key. Your text is sent to that service. Check its terms before translating unpublished work.

Using it

  • Open and close it with the あA button in the toolbar or “View > Show / hide translation”
  • When you turn a page, only the paragraphs visible on screen are translated (up to 40 per screen)
  • Paragraphs already translated are remembered and not translated again when you come back. “Translate again” translates without using the remembered result
  • The 原 button at the top of the pane hides the original text. A－ / A＋ change the size of the translated text
  • Drag the left edge of the pane to change its width
  • Double-click a line of translation, and the matching paragraph in the text lights up for 1.8 seconds, so you can see which translation belongs where

The quality of the translation is the quality of the model you choose. The app does not translate; it only shows what it receives. Smaller models break down more on dialogue, honorifics and proper nouns, and may even invent names. A translation into a language you cannot read cannot be checked as it is. For anything you show others or use for work, have it checked by someone who reads that language, or by a larger model.

10Auto page turn

Choose 10, 15, 20, 30, 45, 60 or 90 seconds, or enter any number from 1 to 3600 seconds with “Custom Interval…”.

  • The seconds left until the next turn are shown on the button in the bottom toolbar
  • If you turn a page yourself, the count starts again from that moment
  • Pages are not turned while reading aloud (read-aloud turns the pages itself). Meanwhile the button shows “—”, and the count starts again when reading ends
  • It stops by itself at the end of the book
  • To stop it, choose “Stop Auto Page Turn” in the same menu
  • It stops when you close the book and go back to the library

11Sleep timer

Choose 15, 30, 45, 60, 90 or 120 minutes, or enter any number of minutes with “Custom Duration…”. To cancel it, choose “Cancel Timer”.

When it expires

Whichever you choose, read-aloud is stopped first.

Stop Speech
Only stops read-aloud (the default).
Sleep this computer
Stops read-aloud, then puts the computer to sleep.
Shut down this computer
Stops read-aloud, then waits 30 seconds before shutting down. The seconds left are shown on the button in the bottom toolbar. If you are still awake, choose “Cancel Timer” during those 30 seconds, and the computer does not shut down.
Sleep and shut down affect the whole computer, not just this app. Do not use them while other apps have unsaved work. On macOS, shut down is requested through System Events, so the first time macOS asks for permission to control System Events. If you do not allow it, the power action is not carried out. On Windows, shutdown is not forced, so it stops if another app refuses to quit. On a machine with hibernation enabled, sleep may hibernate instead.
  • The timer keeps running when you close the book and go back to the library, and you can cancel it from there
  • Quitting the app clears the timer, so a timer from the night before cannot start again and turn the computer off when you launch the app the next day

12Exporting audio and video

Both export the chapter you are reading now, and work only while a book is open.

Save Chapter as Audio… (WAV)
Synthesizes the chapter’s sentences in order and joins them into one audio file. Useful for listening to your own manuscript on the way to work.
Save Chapter as Video… (MP4)
Creates a video combining the look of the text with the spoken audio, at 1920×1080 and 30 frames per second. Vertical or horizontal layout is chosen automatically from the direction of the text on screen. Where MP4 cannot be produced, it is saved as WebM. No screen recorder or video editor is needed.
  • Files are saved to Settings > Speech > Audio save folder. If none is set, the app asks where to save and remembers the folder you choose for next time
  • Audio shows “Synthesizing…” with progress. Video shows a progress bar and a “Cancel” button
  • While reading aloud or exporting, the export items in the menu are greyed out. Exporting from the toolbar buttons stops read-aloud first
  • Exports use the reading dictionary and the voice, speed and pause settings
  • The whole chapter is synthesized, so a long chapter takes time
Before publishing exported audio or video, check the terms of the voice. Audio made with VOICEVOX or AivisSpeech comes with the terms of the voice library you used. Many voices require crediting the character’s name (for example VOICEVOX:四国めたん), and whether commercial use is allowed differs from voice to voice.

13Switching shelves

You can split your whole collection into several shelves (“Work”, “Hobby” and so on). The commands are in the “File” menu.

  • New Shelf… — creates a shelf with the name you enter and switches to it
  • Switch Shelf — lists your shelves; choose one to switch to it
  • Manage Shelves… — switch, rename, delete and add shelves
Kept separately per shelfShared by all shelves
The list of books, collections, favourites, reading positions, bookmarks, the reading dictionary (the “All books” side), the CSS shared by all books, and the last book read App settings (theme, text size, language, speech engine, voice, translation server and so on)

Why switching instead of hiding

A collection can include books you would not show others: data you hold for work, books you would rather your family did not see, books that have nothing to do with the person you are sharing your screen with. With a “hide” design, missing a single path — forgetting to turn hiding back on, covers left in a cache — is enough for them to show. With a design that switches what is read, anything not read cannot be shown. The intended use is to keep a shelf with only books you can show, for screen sharing and screenshots.

  • The original shelf (Library) and the shelf being shown cannot be deleted
  • Deleting a shelf does not erase its data; it is moved to Deleted/ in the data folder, so a mistake can be undone
  • Deleting a shelf does not delete your original book files

14Settings

Open with “Settings…” (⌘,). On macOS it is in the app menu; on Windows it is near the bottom of the “File” menu. The gear button at the top right of the library also opens it. There are three tabs: “Speech”, “Display” and “Translation”.

Changes are saved when you press “Save” and take effect right away. “Close” closes without saving. Changing the language does not require restarting the app; the menus are rebuilt too.

Speech

  • TTS engine (VOICEVOX / AivisSpeech / Custom URL), engine URL, engine status
  • Voice, speed (0.5–2)
  • Pause length (between lines / punctuation)
  • Audio save folder (choose with “Browse…”)
  • The “Test voice” button (shown only on this tab)

Display

  • Font size (0.6–2.5), line height (1.2–2.6), theme
  • Language (Auto / 日本語 / English)
  • Text direction, render mode, binding direction, image page spread, text spread
  • Debug mode — a tool for fixing typesetting. Turn it on, and a “Measuring grid” button appears in the reader toolbar. Pressing it lays a colour ruler over the screen, so a screenshot alone tells you margins and overflow as coordinates

16Troubleshooting

macOS says the app cannot be opened because the developer cannot be verified
This is because of the ad-hoc signature. Allow it once with System Settings → Privacy & Security → “Open Anyway” (chapter 1).
Windows shows “Windows protected your PC”
The app is not signed with a code-signing certificate. Press “More info”, then “Run anyway”.
The buttons disappeared when I opened a book
The toolbars appear when you move the mouse to the top or bottom edge of the screen; they are normally hidden to give the text more room. From the keyboard, ⌘L goes back to the library.
Read-aloud does not start
If the engine is not running, the app tries to start it and shows “Starting the speech engine…” at the bottom. If nothing happens after waiting, or it says “Could not start the speech engine”, check that VOICEVOX or AivisSpeech is installed. With “Custom URL”, the engine is not started automatically; start it yourself. If you changed its port, set the URL in the Speech tab of Settings (VOICEVOX defaults to :50021, AivisSpeech to :10101).
Some files do nothing when dropped on the window
That format is not supported (see “Files it opens” in chapter 1). Unsupported files are ignored on purpose.
A vertical book is shown horizontally (or the other way round)
With the book open, choose from “View > Writing Direction”, or use the text-direction button in the toolbar. It is remembered for that book. MOBI and AZW books always come out horizontal because of the format (chapter 6).
A cover is squashed
Check that the rendering mode is not “As authored”. “Reading-friendly” restores the proportions of SVG covers.
The pictures in a photo book are split across the wrong pages
Press “Shift spread” in the toolbar. It appears only for fixed-layout books.
The text looks cut off at the edges
Add margins with “View > Toggle Margins”, or adjust with “Custom CSS…”.
A book goes under “Other” in the By author view
Right-click the book → “Edit reading” and enter the author’s reading in kana.
I fixed a reading, and another word changed too
A short word is replacing part of a longer word. Move the longer word you want to protect to a higher layer, or add a surrounding-character condition (chapter 8).
The export menu items are greyed out
Either no book is open, read-aloud is playing, or an export is running. Stop it, then try again.
No translation appears
Check “Connection” in Settings → “Translation”. If it does not connect, check that the server is running and the URL is right (and, for a cloud service, the key). Translation cannot start if no model is available. If it says the model only thought and returned no translation, turn on “Cut the thinking short”. If it is slow, raise “Passages at once”, or turn off “Pass the previous passage as context” to lighten the load.
The sleep timer does not put the computer to sleep or shut it down
On macOS, you may not have allowed the System Events permission request shown the first time. Check System Settings → Privacy & Security → Automation. Shutdown stops if another app refuses to quit.
Importing never finishes
For a large fixed-layout book, extracting the cover can take tens of seconds. Wait a little, or press “Stop”.

Where data is stored

Copies of imported books, settings, bookmarks and dictionaries are all stored in this folder:

macOS
~/Library/Application Support/dev.veltrea.epub-reader/
Windows
%APPDATA%\dev.veltrea.epub-reader\
  • books/ — copies of imported books
  • settings.json — app settings
  • library.json / collections.json / dict.json — the books, collections and reading dictionary of the first shelf. Files for shelves you added have # and the shelf’s ID after the name
  • loc-* / bm-* / css-* / dict-* / spread-* / prefs-* — per-book reading position, bookmarks, CSS, dictionary, spread shift and display settings
  • Deleted/ — data from deleted shelves

Deleting this folder resets the app to its initial state (imported books are removed too).

If that does not solve it, please open an issue. It helps to describe which part of the book looked wrong and how (if you can, also how it looks in “As authored”), and whether you are on macOS or Windows.
